<h2 id="projects">项目</h2>

### [HUST Machine Learning](https://github.com/Awliver/HUST-MachineLearning)

**半监督学习实验** · Python / PyTorch

在 Fashion-MNIST 上比较不同标签预算下的监督学习与 FixMatch。包含三随机种子实验、指标汇总、混淆矩阵和复现说明。

### [ChicagoKeyboard](https://github.com/Awliver/ChicagoKeyboard)

**Windows 键盘音效工具** · Python / Qt

为按键添加声音反馈，配合实时可视化键盘。支持按键音效与音量设置、外部音频导入和系统托盘运行。

### [xv6 Records & Notes](https://github.com/Awliver/Xv6-Rocords-Notes)

**操作系统实验与笔记** · C / RISC-V / xv6

记录 xv6 实验中的代码与学习笔记，通过教学操作系统理解底层机制。
